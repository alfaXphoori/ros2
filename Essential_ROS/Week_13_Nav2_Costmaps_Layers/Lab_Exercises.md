# 🛠️ ใบงานปฏิบัติการสัปดาห์ที่ 13: การปรับแต่งเลเยอร์ Costmap 2D

## 💻 ขั้นตอนการทดลอง

### ขั้นตอนที่ 1: วิเคราะห์คอนฟิกเลเยอร์ Costmap 2D
เปิดดูคอนฟิก [`config/costmap_params.yaml`](config/costmap_params.yaml) และตรวจสอบ:
- ค่า Polygon Footprint: `[ [0.20, 0.14], [0.20, -0.14], [-0.20, -0.14], [-0.20, 0.14] ]`
- ค่า `inflation_radius: 0.65`

### ขั้นตอนที่ 2: สังเกตการแสดงผล Gradient ของ Costmap บน RViz2
นำคอนฟิกไปทดสอบรันร่วมกับ Nav2 และสังเกตการขยายตัวของ Gradient ความปลอดภัยรอบสิ่งกีดขวาง
