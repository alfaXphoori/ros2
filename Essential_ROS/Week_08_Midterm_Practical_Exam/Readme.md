## 📊 เกณฑ์การให้คะแนน (Midterm Rubric)
1. **ความสมบูรณ์ของโมเดล URDF (30 คะแนน):**
   - มี Links ครบถ้วน (Chassis, ล้อขับ 2 ข้าง, Caster wheel, เซนเซอร์)
   - มีค่า Inertia Matrix ที่คำนวณถูกต้องตามสเปกมวลและมิติ
   - ผ่านการตรวจสอบคำสั่ง `check_urdf` แบบ 100% ปราศจาก Warning
2. **ระบบควบคุมและความปลอดภัยใน Python (40 คะแนน):**
   - มีโหนด Publisher รับส่งคำสั่ง `/cmd_vel`
   - ผูก `add_on_set_parameters_callback` เพื่อจำกัดความเร็วสูงสุดไม่เกินกำหนด
   - มี Subscriber ตรวจจับอุณหภูมิเซนเซอร์และสั่งลดความเร็วอัตโนมัติเมื่อร้อนเกิน
3. **Launch System & RViz2 Visualization (30 คะแนน):**
   - เขียน Launch File รวมระบบทั้งหมดและเปิด RViz2 แสดงผลโมเดลและแกน TF ได้อย่างถูกต้อง
